# Changelog

Release notes for Play Console are the first lines of each version
(Play allows 500 characters).

## 1.0.0 (build 1)

First release.

- Read PDF, Word, Excel, PowerPoint, OpenDocument, RTF, e-books, Markdown, text, images and ZIP files.
- Read Aloud with your phone's own voices, highlighting each sentence.
- Scan documents with edge detection, filters, ID card and book modes, and text recognition.
- Convert between PDF, Word, Excel, images, text and CSV.
- PDF tools: merge, split, organize, compress, protect, unlock, watermark, page numbers, sign, annotate, fill forms, redact.
- Library with search inside documents, collections and starred files.
- Works offline. No account, no ads, no data collected.
